# Hi, I'm Amrit 👋

Cybersecurity undergrad (7th semester) working at the intersection of **AI and security** — I like building systems that don't just defend, but reason about the attacker too.

## 🔭 What I'm building

- **[CyberShield](https://github.com/Amrit-D452/cybersheild-I4C)** — ML-powered triage for cybercrime complaints. Classifies free-text complaints into NCRP/I4C categories (financial fraud, BEC, ransomware, ...), surfaces applicable IPC/IT-Act sections, and flags risk. Flask REST API + TF-IDF/classifier pipeline + pytest suite, trained on synthetic Indian-English & Hinglish data.
- **[SecureAI](https://github.com/Amrit-D452/SecureAI-Intelligent-Threat-Aware-Communication-Platform-)** — exploring a threat-aware communication platform where an LLM reasons about attacks in real time; you play both the defender and the adversary.

## 🧠 Currently learning

- Red team / blue team fundamentals and threat modeling
- Applied ML for security (anomaly detection, text triage)
- Network security & protocol analysis
